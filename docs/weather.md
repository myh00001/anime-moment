# 城市与天气

设置面板的“城市与天气”提供独立来源选项：城市可以通过 IP 自动定位或按省、市、区县手选；天气可以联网获取或手动指定天气和温度。点击“保存城市与天气 · 立即更新”后，下一张报纸使用新设置。

IP 定位使用 https://ipwho.is/?lang=zh-CN ，位置反映网络出口。天气与手选城市坐标使用 Open-Meteo。所有请求在后台进行，不阻塞拍照与打印。自动城市定位和天气每10分钟更新，获取失败后5分钟重试；超过3小时或跨天的自动天气不显示为当前天气。手动天气一直保留，切换城市后不会复用旧城市天气。

设置保存在 `service/weather-settings.json`，自动天气缓存保存在 `service/weather-cache.json`，均不纳入版本控制。

城市数据：大陆省市区县来自 [Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China) 的 `dist/pca-code.json`（MIT，获取日期2026-10-24），另补充台湾22市县及香港、澳门城市入口。共34个省级地区、366个市级分组、3056个大陆区县；行政区划按数据版本提供，并非在线实时更新。

## 地点打印规则

自动地点：北京、天津、上海、重庆打印市名与区县名，其他地区打印省名与市名。IP 城市和坐标来自 ipwho.is；中文行政区信息根据坐标通过 BigDataCloud reverse-geocode-client 获取，并优先使用行政代码匹配本地省市区目录。IP 定位反映网络出口附近，无法查询区县时只打印已获取的市名，不臆造区名。

手动地点：可以分别勾选“省”“市”“区县”；取消全部勾选时不打印地点。直辖市名称去重，不打印“市辖区”等分组名称。地点预览与保存后的下一张报纸使用同一规则。

省、市、区县与天气选项使用限高260像素的可搜索浮层列表，避免原生长菜单的顶部留白和超出屏幕问题。
